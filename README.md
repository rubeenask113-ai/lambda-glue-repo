# Lambda Glue Repository

This repository contains AWS Lambda and AWS Glue integration code.

## Overview

This project demonstrates integration between AWS Lambda and AWS Glue services for data processing and ETL workflows.

## Getting Started

### Prerequisites

- AWS Account
- AWS CLI configured
- Python 3.9+

### Installation

1. Clone the repository
2. Install dependencies
3. Configure AWS credentials

## Project Structure

- `lambda/` - Lambda function code
- `glue/` - AWS Glue job scripts
- `tests/` - Unit and integration tests
- `docs/` - Documentation
